THE Corporate Translator

created because apparently “I have no idea what I'm doing” needs 47 words and a PowerPoint.

I made this bot to translate indirect phrases to literal brutal meanings.

Example:

Corporate:
“We should touch base offline to align on the key deliverables and ensure we're all singing from the same hymn sheet.”

Human:
“Let's talk about it privately because nobody knows what's going on.”

Features
- Saves you 30mins daily on average of trying to understand what ur boss means*
- Converts LinkedIn-speak into English
- Makes meetings 73% less unbearable*
- Built with Node.js + Slack Bolt
